API Docs

Authentication

Create a key under API Keys. Send it as X-API-Key header, Authorization: Bearer KEY, or ?api_key=KEY (simple GET endpoints). 60 requests/min per key.

Webhooks

Events: payment.success, payment.failed, payment.expired, payment.refunded, webhook.test — sent only after provider verification. Headers: X-Zyvo-Timestamp, X-Zyvo-Signature = sha256=HMAC_SHA256(secret, timestamp + "." + rawBody). Reject if timestamp is older than 5 minutes. Deduplicate on event_id. Reply with any 2xx. Failed deliveries retry with backoff.

{"event":"payment.success","event_id":"ORD..:payment.success","order_id":"ORDER10001","transaction_id":"..","amount":100.0,"currency":"INR","status":"SUCCESS"}

Python (Flask) — create + verify webhook

import hmac, hashlib, time, requests
from flask import Flask, request, abort
SECRET = "your_webhook_secret"; KEY = "ZP_XXXX"; BASE = "https://YOUR-APP.onrender.com"
app = Flask(__name__)
def create(amount, order_id):
    return requests.post(BASE + "/api/v1/payment/create", headers={"X-API-Key": KEY},
        json={"amount": amount, "order_id": order_id, "gateway": "paytm"}).json()["payment_url"]
@app.post("/zyvo-webhook")
def hook():
    ts = request.headers.get("X-Zyvo-Timestamp", "0"); sig = request.headers.get("X-Zyvo-Signature", "")
    body = request.get_data(as_text=True)
    exp = "sha256=" + hmac.new(SECRET.encode(), (ts + "." + body).encode(), hashlib.sha256).hexdigest()
    if abs(time.time() - int(ts)) > 300 or not hmac.compare_digest(exp, sig): abort(401)
    data = request.get_json()
    if data["event"] == "payment.success": print("PAID", data["order_id"])  # fulfil order once per event_id
    return "ok"

Test vs production

Use Paytm Staging credentials first; switch Environment to Production in Gateways only after Paytm approves your account. Never mark an order paid from a redirect or screenshot — only from a verified webhook or /verify.
